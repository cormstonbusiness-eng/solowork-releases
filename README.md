# SoloWork releases

Installers for the SoloWork desktop app.

This repository exists so installed copies can check for updates. It holds
nothing but the published installer and its update metadata — no source code.

**Download the latest version from the
[Releases page](https://github.com/cormstonbusiness-eng/solowork-releases/releases/latest).**

SoloWork keeps itself up to date once installed, so you only need this once.

Source lives in a separate private repository.
